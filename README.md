# SecurePath · Desarrollo Seguro

Plataforma web estática e interactiva para estudiar los siete módulos del material de Desarrollo Seguro.

## Incluye

- 7 módulos de estudio: SDLC, programación segura, web, móvil, APIs, DevSecOps e IA.
- 28 tarjetas de recuerdo activo.
- Banco de 112 preguntas con explicación inmediata.
- Cuestionarios aleatorios de 5, 10, 20 o 48 preguntas.
- 4 simuladores completos de 48 preguntas.
- Biblioteca de repaso transversal.
- Seguimiento local de intentos, errores, temas débiles y tarjetas dominadas.
- Diseño responsive, tema profesional y animaciones progresivas.

## Ejecutar localmente

Abre `index.html` directamente o sirve la carpeta con un servidor estático.
